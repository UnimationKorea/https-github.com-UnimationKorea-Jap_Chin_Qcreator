# 다국어 학습 문제 생성기 - Wireframe & UI 설계서 V2

## 📋 프로젝트 개요 (업데이트)

### 목적
PDF, 이미지, JSON 파일을 업로드하여 **한문, 중국어, 일본어** 학습 문제를 자동으로 생성하는 웹 애플리케이션

### 주요 기능
1. **다중 과목 지원**: 한문(漢文), 중국어(中文), 일본어(日本語)
2. **다양한 파일 형식**: PDF, PNG, JPG, JSON
3. **AI 기반 과목별 맞춤 분석**
4. **생성된 문제 미리보기 및 편집**
5. **다국어 UI 지원** (한국어, 영어, 일본어, 중국어)
6. **결과물 다운로드** (PDF, DOCX, Markdown)

### 지원 과목 상세

| 과목 | 주요 특징 | 분석 포인트 |
|------|----------|------------|
| **한문 (漢文)** | 한자 원문 + 번역문 | 원문 해석, 문법 구조, 한자 의미 |
| **중국어 (中文)** | 현대 중국어 (简体/繁體) | 병음, 성조, 어법, 회화 |
| **일본어 (日本語)** | 히라가나/가타카나/한자 | 읽기, 문법, 한자 읽기, 경어 |

#### 컴포넌트 상세 - 파일 업로드

interface JsonUploadProps {
  subject: string;
  onUpload: (data: any) => void;
}

function JsonUpload({ subject, onUpload }: JsonUploadProps) {
  const [jsonData, setJsonData] = useState('');
  const [isValid, setIsValid] = useState(false);
  
  const handleJsonChange = (value: string) => {
    setJsonData(value);
    try {
      const parsed = JSON.parse(value);
      setIsValid(parsed.subject === subject);
    } catch {
      setIsValid(false);
    }
  };
  
  return (
    <div className="json-upload">
      <CodeEditor
        value={jsonData}
        onChange={handleJsonChange}
        language="json"
      />
      <button 
        disabled={!isValid}
        onClick={() => onUpload(JSON.parse(jsonData))}
      >
        JSON 업로드
      </button>
    </div>
  );
}

## 🚀 API 엔드포인트 (업데이트)

### 과목별 분석 API

```typescript
// 과목 정보 조회
GET /api/subjects
Response: {
  subjects: [
    {
      id: 'hanmun',
      name: '한문',
      supportedFormats: ['pdf', 'png', 'jpg', 'json'],
      analysisFeatures: ['interpretation', 'grammar', 'characters']
    },
    // ... 중국어, 일본어
  ]
}

// 파일 업로드 (과목 지정)
POST /api/upload
Body: {
  subject: 'chinese',
  file: <binary> | <json>
}
Response: {
  uploadId: 'upload_123',
  subject: 'chinese',
  status: 'uploaded'
}

// 과목별 분석 시작
POST /api/analyze
Body: {
  uploadId: 'upload_123',
  subject: 'chinese',
  options: {
    includePinyin: true,
    includeTones: true,
    hskLevel: true
  }
}

// 분석 결과 조회
GET /api/analysis/:id
Response: {
  subject: 'chinese',
  result: {
    pages: [...],
    vocabulary: [...],
    grammar: [...],
    exercises: [...]
  }
}
```

## 💡 개발 시 고려사항 (추가)

### 과목별 AI 프롬프트 전략

**한문 분석 프롬프트**
```
다음은 한문 교재입니다:
[원문 텍스트]

다음을 수행하세요:
1. 원문을 정확히 인식하고 현토를 달아주세요
2. 각 한자의 음(音)과 훈(訓)을 추출하세요
3. 문장 구조를 분석하세요 (주어/서술어/목적어/수식어)
4. 적절한 해석 문제를 생성하세요
```

**중국어 분석 프롬프트**
```
这是中文教材:
[原文]

请执行以下操作:
1. 识别简体/繁体字
2. 为所有汉字标注拼音和声调
3. 分析语法结构
4. 评估HSK等级
5. 生成相关练习题 (拼音、声调、造句)
```

**일본어 분석 프롬프트**
```
以下は日本語の教材です:
[本文]

以下を実行してください:
1. ひらがな・カタカナ・漢字を識別
2. すべての漢字にふりがなを付ける
3. 文法パターンを分析
4. 敬語レベルを判定
5. JLPTレベルを評価
6. 適切な練習問題を生成
```

### JSON 스키마 검증

```typescript
// 과목별 JSON 스키마
const hanmunSchema = z.object({
  subject: z.literal('hanmun'),
  title: z.string(),
  pages: z.array(z.object({
    pageNumber: z.number(),
    originalText: z.string(),
    translation: z.string().optional(),
    characters: z.array(z.object({
      char: z.string(),
      meaning: z.string(),
      sound: z.string()
    }))
  }))
});

const chineseSchema = z.object({
  subject: z.literal('chinese'),
  title: z.string(),
  pages: z.array(z.object({
    pageNumber: z.number(),
    text: z.string(),
    pinyin: z.string(),
    translation: z.string().optional(),
    vocabulary: z.array(z.object({
      word: z.string(),
      pinyin: z.string(),
      meaning: z.string(),
      tone: z.string()
    }))
  }))
});

const japaneseSchema = z.object({
  subject: z.literal('japanese'),
  title: z.string(),
  pages: z.array(z.object({
    pageNumber: z.number(),
    text: z.string(),
    furigana: z.string().optional(),
    translation: z.string().optional(),
    vocabulary: z.array(z.object({
      word: z.string(),
      reading: z.string(),
      meaning: z.string(),
      jlpt: z.string().optional()
    }))
  }))
});
```
